# MetaMuse — 60-Second Judge Demo Script

Rehearse this verbatim. Total: ~60 seconds. Requires: Meta Horizon theme active
(now the first-run default), one demo account with no API keys (proves the
zero-config path), and optionally a second pass with a Meta Model API key.

## Setup (before recording)

- Fresh install, airplane mode ON for the offline pass (or Wi-Fi on, no keys entered).
- Kill and relaunch the app so Lumi opens **Radiant** on the Meta Horizon theme.
- Have a WhatsApp account on the device so the nudge deep-link resolves.

## The 60 seconds

| Time | Action | What the judge sees |
| ---- | ------ | ------------------- |
| 0–10s | Open the app. | Lumi **Radiant ✨**, Meta Blue theme, overall life score high. Say: "This is Lumi — a living mirror of your whole life, not one metric." |
| 10–35s | Tap the science icon → **1. The Success Trap**. | Lumi turns **Sick 🤒**, aura dims; Muse Spark diagnosis card appears: 98% tasks + savings vs 5h sleep + 3 canceled plans; WhatsApp nudge drafted. Say: "High output is secretly borrowing from sleep and friendships — Lumi shows it before burnout." |
| 35–45s | Tap **💬 Open WhatsApp & Reach Out**. | WhatsApp opens with the check-in pre-filled. Say: "One tap turns insight into reconnection." |
| 45–60s | Back in app → **Verify Follow-Through**, then tap 🔊 voice. | Lumi recovers to **Radiant ✨**; Lumi speaks the prescription aloud. Say: "Only verified follow-through heals her — agreement alone doesn't." |

## 30-second extended cut (if time allows)

- Swipe to **Show Data**: 4-channel bio-radar (Health / Tasks / Finance / Social).
- Swipe to **Connections**: Health Connect, Calendar, Facebook, Plaid/SimpleFIN/CSV cards +
  BYOK Keystore status → "your keys never leave this phone."
- Mention: "With a Meta Model API key it reasons in the cloud; without one, the
  on-device engine keeps every demo beat working offline."
