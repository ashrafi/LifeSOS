# LifeSOS / MetaMuse — Final Submission Checklist

Based on the Meta Global AI Developer Hackathon participant guide, these are the highest-priority tasks before submission.

## Must complete

- Record the required 3-minute demo video. This is a primary judging artifact, not just a supplementary clip.
- Show the actual MetaMuse experience: Lumi, the Success Trap scenario, Muse Spark response, action/follow-through, and recovery.
- Clearly identify what was built during the hackathon versus existing code or functionality. The guide warns that unclear hackathon contributions can lead to disqualification.
- Show genuine Meta Model API / Muse Spark usage. Make the model attribution visible and explain its role.
- Make the GitHub repository public and verify that judges can access it.
- Complete the official submission on the Cerebral Valley platform before November 4, 9:00 PM Eastern.
- Appoint one submission representative.
- List every team member who contributed.
- Verify the video link is publicly accessible or accessible to judges.
- Verify the submission information is complete and accurate.

## README and GitHub polish

- Put the video link near the top of the README.
- Add the best screenshots to the README.
- Include concise project description, problem, solution, and Meta AI integration.
- Explain how the project uses Muse Spark / Meta Model API.
- Document setup sufficiently for judges to understand or run the project.
- Ensure no API keys, tokens, credentials, or personal data are committed.
- Clearly distinguish new hackathon work from pre-existing code.

## Demo quality

- Open with the problem and Lumi—not architecture or setup.
- Make the Success Trap story understandable within the first 30 seconds.
- Show the actual Muse Spark response, not just a mocked response.
- Capture Lumi’s Sick → Radiant transformation.
- Keep text readable and animations complete.
- Avoid unnecessary settings screens and long loading periods.
- Keep an offline backup recording in case the live API fails.

## Final compliance checks

- Confirm the project fits Build for Your World.
- Confirm all presented functionality is yours to use and demonstrate.
- Confirm the demo does not present AI as providing medical advice.
- Verify the public repository, video, and submission page one final time.
- Submit before the deadline—do not wait until the last minute.

## Optional promotion / bonus awards

- Post the demo on X if pursuing the Most Viral Project bonus.
- Submit the X post link through the hackathon platform if required.
- Share the project for community voting when the gallery opens.

The guide says judging weights are Impact 30%, Meta AI Tooling 25%, Technical Depth 20%, and Demo 25%. That makes the demo and the explanation of Meta’s contribution especially important.&#x20;

My recommendation: prioritize the three-minute video, public repository, accurate hackathon contribution disclosure, and completed submission form. Everything else is secondary.
